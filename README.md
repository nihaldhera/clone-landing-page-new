# Get Dyversa - USA Hate Bras Hate Braless Landing Page Clone

This repository contains a full local clone of the [Get Dyversa](https://www.getdyversa.com/pages/usahatebrashatebraless) landing page and product page.

## Features
- **Accurate High-Resolution Visual Clone**: Preserves all typography (Fraunces, Josefin Sans, system fonts), high-resolution imagery, comparisons, and custom editorial layout.
- **Responsive Layout**: Works seamlessly across desktop, tablet, and mobile screen sizes.
- **Included Pages**:
  - Landing Page: `http://localhost:3000/` or `http://localhost:3000/pages/usahatebrashatebraless`
  - Product Page: `http://localhost:3000/products/seamlessbra`
- **Mock Shopify Cart API**: Integrated local server (`server.js`) simulating `/cart.js`, `/cart/add.js`, `/cart/update.js`, and `/cart/clear.js` for testing frontend interactions without hitting external Shopify cart barriers.

## How to Run

1. Open a terminal in this directory (`d:\clone landing page`).
2. Start the local server:
   ```bash
   node server.js
   ```
   or:
   ```bash
   npm start
   ```
3. Open your browser and navigate to:
   - [http://localhost:3000](http://localhost:3000)
   - [http://localhost:3000/pages/usahatebrashatebraless](http://localhost:3000/pages/usahatebrashatebraless)
   - [http://localhost:3000/products/seamlessbra](http://localhost:3000/products/seamlessbra)
